    El sello es el SHA-256 del registro. Si alguien edita el JSON (un hash, una fecha, un nombre), deja de coincidir.

    Registros

    Todas las evidencias hasheadas en este equipo.

    Verificar

    Comprueba que una evidencia no ha cambiado desde que se hasheó.

    Desde un informe JSON

    Importa el informe JSON de ForensiX Hash (también de otro equipo). Se comprueba su sello y después puedes verificar la evidencia.

    Desde los registros

    Abre un registro y pulsa «Verificar ahora». Cada verificación queda anotada con quién la hizo y cuándo.

    Cadena de custodia

    Cada operación queda anotada y enlazada con la anterior por su hash: si se borra o edita un evento, la cadena se rompe.

    Acerca de ForensiX Hash

    Herramienta de hashing forense: archivos, carpetas y discos, con verificación automática, datos del caso, cadena de custodia e informes.

    Usa la herramienta solo sobre evidencias propias o con autorización. Para evidencias reales, conecta los discos con un bloqueador de escritura.
